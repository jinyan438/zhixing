# 知行股票

知行股票是一个本地优先的股票分析软件。当前第一阶段完整移植了 Tick Stock Panel 的自选股模块，并把产品入口收敛为自选工作台。

## 当前范围

- 自选股搜索、添加、删除、置顶与清空
- 自选分组的创建、改名、排序、成员管理与分组统计
- 券商截图、CSV、TXT 和粘贴代码批量导入
- 表格与卡片视图、列定制、排序和多条件筛选
- 日 K、分时小图、实时行情更新和个股详情预览
- 深浅主题、响应式导航、数据源与运行设置

策略、回测、因子、财务分析等页面暂未接入产品路由，后续按模块逐步建设。

## 一键启动

双击根目录的 `start.bat`，或在 CMD 中运行：

```bat
start.bat
```

脚本不调用 PowerShell。它会检查依赖、启动前后端，并在服务就绪后自动打开自选页。后端和前端分别在独立窗口运行，关闭对应窗口即可停止服务。

也可以手动分别启动：

```powershell
Set-Location .\backend
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 3118

Set-Location ..\frontend
pnpm install
pnpm dev
```

前端默认地址为 `http://127.0.0.1:3111`，后端默认地址为 `http://127.0.0.1:3118`，可与原程序并行运行。
